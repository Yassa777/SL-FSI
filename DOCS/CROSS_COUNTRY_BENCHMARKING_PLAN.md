## 3. Benchmark Metrics by Country

### 3.1 Metric Definitions

| Metric | Formula | Threshold | Data Required |
|--------|---------|-----------|---------------|
| **Import Cover** | R / (M / 12) | ≥ 3 months | R, M |
| **Greenspan-Guidotti (GG)** | R / STD | ≥ 1.0 | R, STD |
| **IMF ARA** | R / ARA_composite | ≥ 100% | R, X, M2, STD, PL |
| **Jeanne-Ranciere (J-R)** | R / (ρ* × Y) | ≥ 100% | R, STD, Y, calibration |
| **M2 Ratio** | R / (M2 × E) | ≥ 20% | R, M2, E |
| **Reserves/GDP** | R / Y | Context-dependent | R, Y |

### 4.6 Key Script: calculate_metrics.py

```python
"""
Calculate reserve adequacy metrics for all benchmark countries.
"""

import pandas as pd
import numpy as np

def import_cover(reserves: float, monthly_imports: float) -> float:
    """Import cover in months."""
    if monthly_imports <= 0:
        return np.nan
    return reserves / monthly_imports

def greenspan_guidotti(reserves: float, st_debt: float) -> float:
    """Greenspan-Guidotti ratio."""
    if st_debt <= 0:
        return np.nan
    return reserves / st_debt

def imf_ara(reserves: float, exports: float, m2_usd: float,
            st_debt: float, portfolio_liab: float) -> float:
    """
    IMF Assessing Reserve Adequacy metric.

    ARA = 5% × Exports + 5% × M2 + 30% × STD + 15% × Portfolio
    Ratio = Reserves / ARA
    """
    ara = 0.05 * exports + 0.05 * m2_usd + 0.30 * st_debt + 0.15 * portfolio_liab
    if ara <= 0:
        return np.nan
    return reserves / ara

def jeanne_ranciere_optimal(lambda_ratio: float, gamma: float = 0.078,
                            pi: float = 0.10, delta: float = 0.015,
                            sigma: float = 2, r: float = 0.05) -> float:
    """
    Jeanne-Ranciere optimal reserves-to-GDP ratio.

    Returns: optimal rho* (as decimal, e.g., 0.094 = 9.4%)
    """
    term = 1 - (1 - delta) / (1 + r)
    p = (1 + r) / ((1 + r) + pi * term)
    rho_star = lambda_ratio + gamma - (1 - p**(-1/sigma))
    return max(0, rho_star)

def m2_ratio(reserves: float, m2_usd: float) -> float:
    """Reserves to M2 ratio (Guidotti rule for capital flight)."""
    if m2_usd <= 0:
        return np.nan
    return reserves / m2_usd
```

| Country | Pre-Crisis | Crisis Peak | Post-Crisis | Event |

### 5.2 Comparative Analysis Framework

```
For each metric M ∈ {Import Cover, GG, ARA, J-R, M2}:

  1. Calculate M_t for each country c at each time t

  2. Identify breach dates:
     breach_date[c] = first t where M_t < threshold

  3. Calculate lead time:
     lead_time[c] = crisis_date[c] - breach_date[c]

  4. Compare metric performance:
     - Which metric gave earliest warning?
     - Which had fewest false positives?
     - What was M_t at crisis peak?
```
